Shared Ship (co-op)
[h1]Shared Ship (co-op)——共享星舰[/h1]
[i]让合作生涯中的所有玩家都能指挥同一艘星舰并在上面建造。[/i]

[h2]发现 Bug？请不要在评论区反馈[/h2]
[b]请只在 GitHub 上报告 Bug：[/b] https://github.com/UberMorgott/Cosmoteer-Mod-SharedShip/issues

[h2]功能[/h2]
将你的一艘或多艘星舰设为[b]共享[/b]后，同一生涯中的每位人类玩家都可以：
[list]
[*]指挥它：移动、攻击、侧向扫射、直接控制；
[*]使用它的武器并选择目标；
[*]管理它的船员、资源、开关和涂装；
[*]在它上面建造、编辑和维修。
[/list]
共享星舰还会出现在每位队友自己的星舰列表中（编队、选择己方星舰、FTL 准备、通讯）。未共享的星舰保持原版行为。星舰的真正所有者不变：资金、维护费和舰队计数仍归所有者。

[h2]使用方法[/h2]
[list]
[*]选中星舰，在星舰菜单中打开[b]将星舰控制权转移到……[/b]（2 名以上玩家的生涯模式），选择[b]所有人（共享星舰）[/b]。对已共享的星舰，该选项显示为[b]取消共享[/b]。
[*]快捷键：[b]Ctrl+Shift+H[/b]。在星舰名称任意位置加入 [b][S][/b] 效果相同。
[*]同一菜单中的[b]自己[/b]会接管所选星舰：队友的共享星舰变为你的私有星舰。
[*]选择某位玩家（原版功能）会把星舰转移给他；共享星舰同时变为私有。
[*]若要让队友的星舰协助建造或补给，请把这些星舰的[b]建造辅助[/b]设为[i]所有友方星舰[/i]。
[/list]

[h2]前置要求[/h2]
[list]
[*][b]Yet Another Mod Loader[/b]（创意工坊 3577650065），按其说明安装。
[*]在游戏内的模组列表中启用 Shared Ship，并在那里[b]信任[/b]它的库文件。
[*][b]所有玩家必须使用完全相同版本的本模组。[/b]没有安装或版本不同的玩家会发生不同步。
[/list]

[h2]已知限制[/h2]
[list]
[*]取消共享只会取消队友的直接控制；他们的其他命令会保留，直到被新命令替换。
[*]两名玩家同时在同一艘共享星舰上建造时，未完成的编辑可能互相覆盖。
[*]建造和维修费用由下达命令的玩家支付。
[*]船员转移、资源交易和资金仍按所有者计算（原版规则）。
[/list]

支持语言：英语、俄语、德语、西班牙语、法语、日语、葡萄牙语（巴西）、简体中文。
